# Income Classification Project

## Описание задачи
Цель проекта — построить модель для классификации уровня дохода (>50K или <=50K) на основе характеристик пользователей.

Результат может быть использован для таргетирования маркетинговых предложений на платежеспособную аудиторию.

---

## Используемые данные
Датасет содержит информацию о пользователях:
- возраст
- образование
- род занятий
- семейное положение
- рабочие часы
- и другие признаки

---

## Этапы работы
- Проведен разведочный анализ данных (EDA)
- Выявлены ключевые признаки, влияющие на доход
- Обучены модели:
  - Logistic Regression
  - Decision Tree
  - Random Forest
  - Gradient Boosting
- Проведено сравнение моделей
- Настроен порог классификации

---

## Выбор модели
Gradient Boosting значительно превосходит остальные модели по precision (~0.80 против ~0.57–0.49), что делает его наиболее подходящим для решения задачи.

---

## Настройка порога
Выбран порог **0.5**, обеспечивающий баланс между precision и recall с учетом приоритета минимизации ложных срабатываний.

---

## Результаты
- Precision (>50K): ~0.80
- Recall (>50K): ~0.62
- Accuracy: ~0.87

---

## Вывод
Полученная модель может быть использована для эффективного таргетирования маркетинговых предложений.

---

## Ограничения
